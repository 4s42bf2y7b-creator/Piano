# 🎹 Piano Star

A 10-minute daily streak piano learning app for kids. Supports touch piano on iPad and MIDI keyboard input (Casio CT-S1100 and compatible).

## Features
- 6 songs × 3 levels (Roar, Firework, 7 Rings, Let It Go, bad guy, Shake It Off)
- Falling notes visualiser (Synthesia-style)
- Touch piano with MIDI support
- 10-minute session timer
- Daily streak tracking
- Auto difficulty progression

## Local dev

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push to GitHub
2. Import repo at vercel.com
3. Framework: **Vite** (auto-detected)
4. Deploy — done

No environment variables needed.

## Keyboard shortcuts (desktop testing)

`A S D F G H J K` = white keys (C D E F G A B C)
`W E T Y U`       = black keys
